Dev Wrapped is a Spotify-Wrapped-style year-in-review for developers. Type a GitHub username or owner/repo and get a gorgeous, shareable recap: total commits, longest streak, top languages, the hour you do your best work, and a collectible "developer persona" (Night Owl, The Refactorer, Ship-It Gremlin, and rarer tiers). The output is a self-contained animated HTML story plus PNG share cards and an embeddable README badge. Works as a web app, a Claude Code skill/plugin, or a CLI. No API key, no signup — local mode is pure git log, so your data never leaves your machine. Open source (MIT).
