I built SkillView to make agent skills easier to inspect and maintain. Discover skills, read their SKILL.md files before installing, see what is already installed, and review updates or cleanup from a terminal UI. It runs as a GitHub CLI extension or a standalone app, with CLI commands for scripting the same work.
