Promptring adds real desktop banners to GitHub Copilot CLI so you instantly know when tasks finish, need input, or get blocked. It is cross-platform across macOS, Windows, Linux, and WSL, with a lightweight setup centered on Python 3. The project is practical and focused: reliable lifecycle-hook notifications, session-aware messages, and customizable categories and sounds.
