A free browser-only utility for developers making repositories easier for coding agents to work in. Users paste an AGENTS.md draft and get a readiness score, category breakdown, and copyable fix plan covering setup instructions, exact commands, repo map, coding conventions, PR expectations, safety boundaries, nested scope, and maintenance cues. It is static, local-first, and does not require signup.
