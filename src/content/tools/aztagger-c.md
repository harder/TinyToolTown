AzTagger is a cross-platform desktop GUI application for fast and flexible querying of Azure resources and tag management. It allows fast search and filtering of all resources, resource groups, and subscriptions using Azure Resource Graph for your Entra ID tenant. It runs on latst Windows 11 (WPF), macOS (Mac) and Linux (GTK). I built it for speeding-up the daily work with tags on Azure resources, mainly for myself but also some colleagues how felt the same kind of pain. It's also surprisingly useful for just querying resources in very large setups.
