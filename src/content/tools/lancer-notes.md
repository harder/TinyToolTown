## This is Markdown Editor that is both feature rich and lightweight. 
It can be used for learning Markdown, or treated as basic WYSIWYG editor, like WordPad, or basic MarkdownPad. 
Inspired from (now loss media, only found what I remember) of Lancer Fan Club Forum by ObjectPresents and not being able to use MarkdownPad, I created Lancer Notes.
