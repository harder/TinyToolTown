Monthly brings up to 12 Google Analytics 4 properties into one self-hosted dashboard. It was built to make checking traffic across several projects easier, without editing configuration files or jumping between GA4 properties.

Add one or several properties, compare 7, 30, or 90 days with the previous period, and scan traffic and acquisition charts. Standard view shows the details; Mini view fits four projects per desktop row. Copy or download the complete report as Markdown or JSON.

Run it locally or on a server you trust and bring your own Google service-account key. Google API calls run on that server, not only in the browser. A built-in synthetic demo lets you try the interface without credentials. There is no paid tier, and the project uses the permissive 0BSD license.

The linked screenshot shows only the built-in synthetic demo, not real analytics or account details.
