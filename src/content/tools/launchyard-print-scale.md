A small, free browser tool for home-print sizing problems. Choose A4 or US Letter, download a 100 × 100 mm proof PDF, measure its horizontal and vertical sides with a ruler, and enter the measurements. If the axes disagree, it warns that one scale percentage cannot fix both directions.

The complete standalone UI and PDF/diagnostic core are MIT licensed in tools/print-scale/ of the linked repository. The repository also contains a separate small JSON translation checker; this submission is for the print tool only.

The PDF dimensions, calculation and local server/API behavior were checked. A physical printer test and a complete browser verification have not been performed, and the page explains those limits. The hosted version counts aggregate HTML requests and has optional session-based research controls; measurements are not uploaded. The standalone version has no analytics. No ads, checkout or subscription are currently active.
