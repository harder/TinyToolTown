Web Performance Budget Gate is a zero-dependency Node.js CLI for checking saved Lighthouse JSON against explicit route-level budgets. It gives separate outcomes for a pass, a completed budget failure, and incomplete evidence, so a missing capture cannot look like a successful check. It reads local files only; it does not run Lighthouse, fetch a live page, or measure real-user performance. The public repository includes synthetic passing and failing fixtures.

This is a free, MIT-licensed tool maintained by Edilec. I am associated with Edilec. This submission was prepared with AI assistance and checked against the public README, v1.0.0 release, and passing tests. The linked thumbnail is a conceptual illustration, not a screenshot of measured results.
