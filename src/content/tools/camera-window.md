This tool creates a separate camera window. I made this to solve a problem that I was having which is that I couldnt find a desktop application which accesses your laptops camera. I needed a tool like this for screen recording videos since I make content on youtube. OBS has a seperate camera window functionality but it didnt have certain features I was looking for like the window staying infront of other applications even when the cursor is being click on a web app.
