Extension with unique capabilities for Markdown table formatting in VS Code like compact mode, smart max-width formatting, row numbers, table transposition, smart mode detection, and multiple sort options that you won't find in other extensions. I built it because I prefer reading Markdown in code view and was annoyed about existing table formatting possibilities.
