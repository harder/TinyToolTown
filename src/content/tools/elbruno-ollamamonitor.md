ElBruno.OllamaMonitor is a tiny Windows system tray companion for anyone running Ollama locally.

It shows at a glance whether Ollama is available, which models are currently loaded, and how much CPU, RAM, and GPU the Ollama process is using.

I built it because I wanted instant feedback while developing and presenting local AI demos, without keeping terminals or Task Manager open. It also includes a compact always-on-top monitor and simple actions to start Ollama, stop models, pull or remove models, and copy model names.

Tiny, practical, and delightfully nerdy.
