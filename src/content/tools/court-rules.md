Court Rules structures judge-specific filing rules, local and federal court rules, court holidays and privacy-enforcement data for US courts, with a free deadline calculator and an API and MCP server for legal-tech platforms. Every district has its own local rules and many judges add standing orders; Court Rules lists them side by side for each court and judge. The deadline calculator counts calendar days, business days and court days and applies each district's holidays. A public API and an MCP server serve the same data to legal-tech tools and AI assistants. Court Rules is free to use.
