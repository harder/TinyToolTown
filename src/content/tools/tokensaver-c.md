A Roslyn-powered MCP server built for .NET. It hands AI coding agents token-reduced views of your C#, VB.NET and Razor source — minify a whole file, outline its types, focus a single method with its helpers, or trace callers. Typical savings: 30–95% of tokens,
with no loss of logic in read operations.

By using the tool we can all help out to reduce the tokens spent, at https://tokensavermcp.com you can track your own/community saved tokens and energy. This is driven by telemetry data sent to a shared server, you can read more about it at the github page or webpage.
