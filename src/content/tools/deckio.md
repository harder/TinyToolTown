DECKIO lets you create slide decks by talking to an AI agent. Describe your talk, get a scaffolded deck back in seconds — every slide is a React + JSX component, every piece of text is editable inline, and the AI keeps iterating with you turn by turn. Built on Vite + React so decks live in version control, get reviewed in PRs, and never crash on the projector. Comes with `npx create-deckio` to spin up a new deck in one command and an open-source component library to build your own slide types.
