Xprite is a free, open-source browser editor focused on pixel art and frame-by-frame sprite animation. Draw with a mouse, touch, or stylus, work with layers and animation frames, open and save .ase/.aseprite projects, and export PNG or GIF. Core editing requires no account, payment, or trial, and artwork is edited and stored locally on the visitor's device.

It brings a familiar pixel-editing workflow to desktop, tablet, and phone browsers. You can continue an existing sprite project when your usual desktop editor is not available, or share the editor link and project file so another person can view and edit it without installing software. The interface supports English and Chinese.
