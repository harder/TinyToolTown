A lightweight Windows Forms utility that types configured text blocks into any focused application using a global hotkey combination. Perfect for demos, tutorials, and repetitive typing tasks, it features human-like typing delays, system tray integration, and automatic theme-aware icon generation. Settings persist in JSON and the hotkey remains active even when minimized to the background.
