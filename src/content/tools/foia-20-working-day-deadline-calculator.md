FOIA 20 Working Day Deadline Calculator is a tiny local-first web tool for estimating the federal FOIA 20-working-day determination target from a request clock-start date. It excludes Saturdays, Sundays, and standard U.S. federal holidays, supports optional tolling / pause days, adds an optional 10-working-day unusual-circumstances extension target, and exports a source-linked memo, CSV row, or local calendar hold.

I built it because FOIA requesters, journalists, researchers, public-records volunteers, and civic teams often need a quick tracker date without pasting request text into a hosted system. The tool is deliberately narrow and local: no signup, no cookies, no analytics, no beacons, no external scripts, no uploads, and no browser storage.
